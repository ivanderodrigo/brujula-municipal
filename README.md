# Overlay Brújula Municipal v1.5

## Uso recomendado
Este ZIP se copia **encima del repositorio completo actual**. No borres los ficheros que ya tienes.

Después:
1. commit de los ficheros del overlay;
2. Actions → `Aplicar Brújula v1.5 visual + hotfix` → Run workflow;
3. al terminar en verde, ejecutar tu workflow normal `Actualizar datos de Brújula Municipal` con modo `full`.

Así conservas todo el contenido y aplicas el rediseño y los hotfix sin reconstruir desde una demo reducida.
